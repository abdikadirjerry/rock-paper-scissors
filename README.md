# Rock Paper Scissors

A simple Rock Paper Scissors game built with HTML, CSS, and Vanilla JavaScript.

## Features

- Player can choose Rock, Paper, or Scissors
- Computer generates a random choice
- Winner is determined automatically
- Player and computer choices are displayed
- Score tracking
- Reset game functionality
- Responsive and simple user interface

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## How to Play

1. Choose Rock, Paper, or Scissors.
2. The computer will randomly choose one.
3. The game determines the winner.
4. The score is updated automatically.
5. Click "Reset Game" to reset the scores and start again.
